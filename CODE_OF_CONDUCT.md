# Code of Conduct

## Our Commitment

KeystoneGrid is committed to providing a welcoming, respectful, and inclusive environment for everyone who participates in the project.

We expect all contributors, maintainers, reviewers, users, and community members to interact professionally and constructively.

## Expected Behavior

Participants are expected to:

* Treat others with respect.
* Communicate constructively.
* Assume good intentions while addressing disagreements.
* Provide useful and respectful technical feedback.
* Accept different perspectives and approaches.
* Focus criticism on ideas and implementations rather than individuals.
* Respect project maintainers, contributors, and community members.
* Follow the project's technical and security processes.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination.
* Personal attacks.
* Threats or intimidation.
* Deliberate disruption of project discussions.
* Publishing private information without permission.
* Sexual harassment or unwanted sexual attention.
* Trolling or repeated bad-faith participation.
* Deliberately obstructing legitimate project work.
* Any other conduct that would reasonably make participation unsafe or hostile.

## Technical Disagreement

Technical disagreement is expected in an open-source project.

Strong disagreement is acceptable when expressed respectfully.

Participants should challenge:

* Designs
* Assumptions
* Implementations
* Security models
* Architectural decisions

They should not attack the people proposing them.

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Maintainers may take appropriate action when behavior violates these standards, including:

* Asking participants to modify their behavior.
* Removing inappropriate comments or contributions.
* Temporarily restricting participation.
* Permanently restricting participation when necessary.

Enforcement decisions will be made with the goal of protecting the project and its community.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers privately.

For security vulnerabilities, do not use public GitHub issues. Follow the process described in `SECURITY.md`.

## Scope

This Code of Conduct applies to project repositories, issue trackers, pull requests, documentation, project communication channels, and other spaces where participants represent or contribute to KeystoneGrid.
